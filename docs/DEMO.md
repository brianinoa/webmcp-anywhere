# Demo video script — WebMCP Anywhere (target 3:00)

Recording notes
- Record at 1920x1080, 30 fps, browser zoomed to 125% so tool names are legible. Screen-record with system audio off; narrate over it afterwards.
- Primary client: ChatGPT desktop app built-in browser (GPT-5.6 Sol or Terra). If spike step 5d/5e fails, swap every "ChatGPT" shot for Chrome 152 + Model Context Tool Inspector (Gemini mode) — the shot list is identical, only the side panel changes.
- Content rules (from CLAUDE.md): no copyrighted media, no third-party logos beyond what is unavoidably on screen in a browser chrome. For the YouTube segment use **only our own upload or a Creative Commons-licensed video** (filter YouTube search by Features > Creative Commons, and prefer something like a NASA or Blender Foundation upload; verify the CC BY badge under the video before recording). Do not play audio from the video in the final cut.
- Music: royalty-free only. Suggested: YouTube Audio Library (studio.youtube.com > Audio Library, filter "Attribution not required"), or Pixabay Music (https://pixabay.com/music/), or Kevin MacLeod / incompetech (CC BY, add credit in description). Keep it at -20 dB under narration.
- Keep DevTools console open in a narrow bottom dock in shots 2–4 with the filter `[webmcp-anywhere]` so tool calls are visibly logged.
